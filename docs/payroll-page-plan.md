# 급여 기록 정리 및 페이지 기획안

## 1. 자료 개요

첨부 자료는 개인 급여/상여/세금/입금액 기록과 연봉 상승 시뮬레이션이 섞여 있는 스프레드시트성 데이터다. 일부 한글은 인코딩이 깨져 있지만, 날짜와 금액 구조는 비교적 명확하게 읽힌다.

주요 축은 다음과 같다.

| 영역 | 설명 |
| --- | --- |
| 월별 급여 기록 | 일자, 구분, 기본급, 초과근무, 세전, 세액, 세후 입금액, 비고 |
| 연간 원천/급여 기록 | 근무년도, 만 나이, 한국 나이, 원천징수 또는 연봉성 금액, 근무지, 비고 |
| 성과/상여 기록 | 연도별 상여, 격려금, 성과급, 포상 등 비정기 입금 |
| 장기 시뮬레이션 | 2024년 이후 연봉 상승, 월급 환산, 계약/대출/주택 구입 목표 추정 |
| 메모성 목표 | “원천 7천 넘기 전에는 집 사야함” 같은 재무 목표 메모 |

상단 누적 합계로 보이는 값은 다음과 같다.

| 항목 | 금액 |
| --- | ---: |
| 기본급 누계 | 268,772,281 |
| 초과근무 누계 | 8,395,372 |
| 세전 누계 | 349,293,098 |
| 세액 누계 | 72,208,261 |
| 세후 입금 누계 | 277,278,155 |

## 2. 월별 급여 기록 구조

월별 급여 기록은 대략 아래 컬럼으로 정리할 수 있다.

| 컬럼 | 의미 | 페이지 표시 방식 |
| --- | --- | --- |
| 일자 | 급여/상여 입금일 | 월별 타임라인, 급여 상세 |
| 구분 | 월급, 상여, 포상, 정산 등 | 필터 칩, 색상 배지 |
| 기본급 | 해당 월 기본급 | 월별 표/그래프 |
| 초과근무 | 초과근무 수당 | 별도 막대 또는 누적 표시 |
| 세전 | 공제 전 총액 | KPI, 추이 그래프 |
| 세액 | 공제/세금성 금액 | 공제율 계산 |
| 세후 입금 | 실제 입금액 | 가장 중요한 메인 지표 |
| 비고 | 정산, 포상, 대출 차감, 공제 메모 | 상세 펼침 |

## 5. 데이터 정리 규칙 제안

페이지를 만들기 전에 원자료를 아래 구조로 정규화하는 것이 좋다.

```ts
type PayrollEntry = {
  id: string
  date: string
  year: number
  month: number
  type: 'salary' | 'bonus' | 'award' | 'settlement' | 'other'
  basePay: number | null
  overtimePay: number | null
  grossPay: number
  taxAmount: number | null
  netPay: number
  note: string
}

type AnnualIncome = {
  year: number
  age: number
  koreanAge: number
  taxableIncome: number | null
  grossIncome: number | null
  workplace: string
  note: string
}
```

## 6. 페이지 기능 제안

### 6.1 대시보드

첫 화면에는 “올해/작년/전체”를 빠르게 비교할 수 있는 카드가 좋다.

필수 KPI:

| KPI | 설명 |
| --- | --- |
| 올해 세전 합계 | 월급+상여+포상 포함 |
| 올해 세후 입금 합계 | 실제 계좌 유입 기준 |
| 올해 세액/공제 합계 | 세전 대비 공제율 계산 |
| 월 평균 실수령 | 세후 입금 기준 평균 |
| 최근 월급 | 가장 최근 월급성 항목 |
| 전년 대비 상승률 | 세전/세후 각각 비교 |

### 6.2 월별 급여 타임라인

월별 리스트는 표보다 카드형 타임라인이 보기 좋다.

카드 구성:

- 날짜
- 구분 배지: 월급, 상여, 포상, 정산
- 세후 입금액 크게 표시
- 세전, 세액, 기본급, 초과근무는 접힌 상세
- 비고는 하단 메모로 표시

### 6.3 차트

추천 차트:

| 차트 | 목적 |
| --- | --- |
| 월별 세후 입금 막대 그래프 | 실제 현금흐름 파악 |
| 세전/세후 비교 라인 | 공제 영향 확인 |
| 기본급 추이 라인 | 연봉 상승 체감 |
| 상여/포상 이벤트 마커 | 큰 입금이 발생한 달 표시 |
| 공제율 차트 | 세액/세전 비율 확인 |

### 6.4 필터와 태그

필터:

- 연도
- 구분: 월급, 상여, 포상, 정산
- 근무지
- 세후 입금 300만 이상/500만 이상
- 초과근무 있음
- 비고 있음

태그 자동화:

- “연말정산”
- “성과급”
- “포상”
- “격려금”
- “대출 차감”
- “건강보험 추가 공제”
- “초과근무”

### 6.5 연봉/원천 시뮬레이터

자료 안에 이미 장기 시뮬레이션 흔적이 있으므로, 별도 기능으로 빼면 좋다.

기능:

- 현재 연봉 입력
- 매년 상승률 입력
- 상여 예상액 입력
- 세후 월 실수령 추정
- 원천 7천만 원 도달 예상 연도
- 주택 구입 목표 연도 계산
- 대출/저축/상여 반영 시뮬레이션

### 6.6 목표 관리

자료의 핵심 메모가 “원천 7천 넘기 전에는 집 사야함”이므로, 목표 관리가 있으면 좋다.

목표 카드 예시:

| 목표 | 지표 |
| --- | --- |
| 원천 7천 이전 주택 구입 | 예상 도달 연도, 남은 기간 |
| 실수령 월 평균 400만 이상 | 최근 12개월 평균 |
| 연간 세후 입금 5천만 이상 | 연간 누적 |
| 상여 포함 원천 7천 돌파 | 상여 포함/제외 비교 |

### 6.7 데이터 입력/수정

초기에는 수동 입력보다 CSV 붙여넣기 기능이 편하다.

기능:

- 엑셀/CSV 붙여넣기
- 컬럼 자동 매칭
- 숫자 쉼표 자동 제거
- 깨진 한글 비고는 별도 원문 보존
- 잘못된 행 검출
- 중복 날짜/구분 경고

## 9. 주의할 점

- 원자료 일부 한글이 깨져 있으므로 비고 원문은 별도 보관하는 것이 좋다.
- 세전/세액/세후가 항상 정확히 계산식으로 맞지는 않는다. 연말정산 환급, 대출 차감, 공제 환급 등이 섞여 있기 때문이다.
- “원천”, “세전”, “연봉”, “상여 포함 연간 총액”은 서로 다른 개념이므로 페이지에서 명확히 구분해야 한다.
- 월급성 항목과 상여/포상 항목을 같은 그래프에 섞으면 해석이 어려우므로, 기본값은 분리 표시가 좋다.

## 10. 한 줄 방향성

이 페이지는 단순 급여 기록표보다 “내 연봉 성장, 실제 현금흐름, 세금/공제, 집 구입 타이밍을 한 번에 보는 개인 재무 대시보드”로 만드는 것이 가장 좋다.
